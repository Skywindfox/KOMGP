KOMGP  v0.1-test  (Windows)
KitsuneOS Music Game Player

一个用 Java 写的 4K 下落式音游，读取 Malody 的 .mcz 与 KOMGP 的 .kmt 明文谱面。

────────────────────────────
运行要求
────────────────────────────
  Java 17 或更高版本（需要带图形界面的 JRE）。
  没有的话去 https://adoptium.net/ 下载安装，装完重新双击 KOMGP.exe 即可。

  如果系统里装了多个 Java，可以设置 JAVA_HOME 指向想用的那个；
  也可以把便携版 JRE 放到本目录下的 runtime\ 里（会优先使用）。

────────────────────────────
怎么玩
────────────────────────────
  1. 双击 KOMGP.exe 启动（不会弹黑框）
  2. 首次启动会在本目录自动生成 3 首演示曲（charts\ 下）
  3. 选曲页：↑↓ 选歌，←→ 换难度，Enter 开始
  4. 默认键位：D F J K（可在"设置"里改）

  自己的谱面：把 .mcz / .kmt 放进 charts\ 目录（可建子文件夹），
  在选曲页按 R 刷新；也可以把谱面文件拖到 KOMGP.exe 上。

────────────────────────────
谱面编辑器
────────────────────────────
  在选曲页按 E 打开。
    左键      放置 / 删除音符
    右键      删除音符
    滚轮      滚动时间轴    Shift+滚轮  缩放
    空格      播放 / 暂停
    1-5       切换网格（1/4 ~ 自由）
    F2        保存为 .kmt（纯文本，可直接用记事本改）
    F3        导出 Malody 包 .mc
    Ctrl+Z    撤销
  N           新建谱面（从 charts\ 里挑一个音频）

  .kmt 是纯文本格式，头部一行 "KOMGP CHART 1"，后面是 key value 和
  "note 时间(ms) 列号 [按住时长(ms)]"，可以直接手写。

────────────────────────────
常用按键
────────────────────────────
  D F J K    4K 打歌键
  Esc        暂停 / 返回
  [ ]        微调本曲延时（±1ms）
  , .        微调本曲延时（±10ms）
  E          打开谱面编辑器（选曲页）
  F11        全屏
  R          重新扫描曲库（选曲页）

────────────────────────────
目录说明
────────────────────────────
  KOMGP.exe         启动器
  KOMGP.jar         游戏本体
  lib\              音频解码库（OGG / MP3）
  charts\           曲库
  config.json       设置与成绩（首次运行后生成）
  debug-console.bat 出问题时的调试入口（会显示控制台输出）

  整个目录可以随意搬动，绿色解压即用。

────────────────────────────
常见问题
────────────────────────────
  Q: 双击没反应 / 弹窗说找不到 Java
  A: 装一个 JRE 17+（https://adoptium.net），或者设置 JAVA_HOME。
     想知道具体原因就双击 debug-console.bat，能看到完整报错。

  Q: 画面卡顿
  A: 设置里把"目标帧率"设成 60，关掉特效；本作是纯 Java2D 软件渲染，
     集成显卡也能跑，很老的机器建议降低窗口分辨率。

  Q: 没有声音
  A: 走系统默认输出。若声音和画面不同步，用设置里的"全局音频偏移"补偿
     （蓝牙耳机通常需要 +80 ~ +200ms）。

  详细说明见 README.md（同目录）。
